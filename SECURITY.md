# Security Policy

## Supported versions

The latest released `0.x` version receives security fixes.

| Version | Supported |
| ------- | --------- |
| 0.1.x   | ✅        |

## Reporting a vulnerability

Please **do not** open a public issue for security vulnerabilities.

Instead, email **[support@viprasol.com](mailto:support@viprasol.com)** with:

- a description of the issue and its impact,
- steps to reproduce, and
- any relevant logs or proof-of-concept.

We aim to acknowledge reports within **72 hours** and to provide a remediation
timeline after triage. Responsible disclosure is greatly appreciated, and we are
happy to credit reporters once a fix is released.

## Scope reminder

Never commit secrets. `.env`, `*.pem`, `*.key`, and `secrets/` are git-ignored by
default — keep it that way.
